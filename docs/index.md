<h1>一个 Key，接所有模型</h1>

<p class="sub">
  ZZM API 是统一模型网关。创建令牌、选分组、填地址，就能在 Claude Code、Codex、Gemini CLI、Cherry Studio 里用上 GPT、Claude、Gemini、Grok。
</p>

## 三步跑通

<div class="zzm-home-steps">
  <a class="zzm-step-card" href="/quick-start">
    <span class="num">1</span>
    <h3>注册 & 创建令牌</h3>
    <p>注册账号，充值，创建令牌。复制 Key，去操练场测试。</p>
  </a>
  <a class="zzm-step-card" href="/groups">
    <span class="num">2</span>

  </a>
  <a class="zzm-step-card" href="/coding-agents/">
    <span class="num">3</span>
    <h3>配软件</h3>

  </a>
</div>
