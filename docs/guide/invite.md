# 拉新有礼

拉新有礼用于给邀请人发放余额奖励。好友通过你的邀请关系注册并充值后，你可以获得一笔奖励。

## 入口

- 拉新页面：<https://zzmapi.zzmsgdsg.xyz/invite>
- 控制台入口：登录后在侧边栏或钱包页进入

## 奖励规则

当前规则按被邀请人的充值额度计算：

| 条件 | 说明 |
| --- | --- |
| 好友完成充值 | 奖励按好友实际到账额度计算 |
| 奖励比例 | 邀请人获得 10% 等值余额 |
| 预计到账时间 | 好友充值完成 72 小时后可领取 |
| 最低领取金额 | 可领取奖励满 5 元后才能领取到余额 |

用户侧看到的是“预计到账中”“可领取”“人工确认中”“已入余额”等状态，不会显示内部账务术语。

## 为什么不是充值后立刻到账

奖励有 72 小时确认期，用来处理退款、异常充值和明显的小号互邀。

如果系统识别到同 IP、异常关系或其他风险，奖励会进入人工确认。人工确认期间奖励不会自动进入余额。

## 如何领取

1. 打开 [拉新有礼](https://zzmapi.zzmsgdsg.xyz/invite)
2. 查看当前可领取金额
3. 满 5 元后点击 `领取到余额`
4. 领取成功后，余额会进入你的钱包

如果没有可领取金额，先看预计到账时间和状态说明。

## 常见情况

### 好友充值了，但我没看到可领取

先看：

- 是否还在 72 小时确认期
- 可领取金额是否满 5 元
- 是否进入人工确认

### 同一个 IP 邀请小号可以吗

不建议这样做。同 IP、异常注册或明显自拉小号可能进入人工确认，超级管理员有权阻止这类奖励发放。

### 奖励可以提现吗

当前奖励用于站内余额，主要用于调用模型，不按现金提现处理。
