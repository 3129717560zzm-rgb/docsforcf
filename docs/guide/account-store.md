# 账号商城

账号商城用于展示可购买的 AI 会员账号、成品号和卡密商品。

## 入口

- 站内商城：<https://zzmapi.zzmsgdsg.xyz/account-store>
- 原始商城：<https://pay.ldxp.cn/shop/XWVMJFMC>

站内页面负责展示和筛选商品，最终购买、付款、发货和售后规则以链动小铺商品详情页为准。

## 适合购买什么

常见商品包括：

- ChatGPT 账号或会员账号
- Claude 账号或会员账号
- 其他 AI 工具账号、卡密、成品号

商品分类后续可能会调整。文档只说明入口和流程，不承诺每个分类长期固定。

## 购买流程

1. 打开 [账号商城](https://zzmapi.zzmsgdsg.xyz/account-store)
2. 按分类或关键词筛选商品
3. 点击 `查看并购买`
4. 跳转到链动小铺商品页
5. 在商品详情里确认有效期、发货格式和售后说明
6. 完成支付后按发卡平台提示取货

## 下单前先看这几项

| 项目 | 为什么要看 |
| --- | --- |
| 有效期 | 确认账号或服务能用多久 |
| 发货格式 | 确认是自动发货、卡密，还是需要人工处理 |
| 售后范围 | 确认什么情况能换、什么情况不处理 |
| 使用限制 | 有些账号不适合频繁切换地区或多人共用 |

## 和 API 余额的关系

账号商城商品不是 ZZMAPI 余额。

- API 余额用于调用模型和接口
- 账号商城用于购买 AI 账号或会员商品
- 两者入口不同，订单也分开处理

如果你只是要调用 API，请去 [充值 / 续费](/guide/recharge)。

## 需要售后怎么办

先看链动小铺商品详情页里的售后规则。如果需要联系站长，带上：

- 商品名称
- 订单号
- 购买时间
- 问题截图

不要在截图里暴露账号密码、API Key 或完整邮箱。
