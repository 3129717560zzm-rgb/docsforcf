# 注册账号

先把账号登录进去，后面所有步骤都在控制台里做。

## 打开控制台

- 控制台首页：<https://zzmapi.zzmsgdsg.xyz>
- 令牌页：<https://zzmapi.zzmsgdsg.xyz/console/token>
- 操练场：<https://zzmapi.zzmsgdsg.xyz/console/playground>

## 注册和登录

1. 打开控制台首页。
2. 按页面提示注册账号。
3. 注册完直接登录。

目前以用户名注册登录为主。

![ZZM API 注册登录页面](/screenshots/zzm-login.png)

## 登录后先看什么

登录后先确认这几个入口能打开：

- `控制台首页`
- `钱包 / 充值`
- `令牌管理`
- `操练场`
