# 注册账号

先把账号登录进去，后面所有步骤都在控制台里做。

## 打开注册页

- 控制台首页：<https://zzmapi.zzmsgdsg.xyz>
- 注册页：<https://zzmapi.zzmsgdsg.xyz/register>

打开首页后，右上角点 `注册`。

![ZZM API 首页右上角注册按钮](/screenshots/zzm-login-register-button.png)

## 填注册信息

按页面顺序填写：

1. 用户名
2. 密码
3. 确认密码
4. 勾选协议
5. 点 `注册`

目前以用户名注册登录为主。

![ZZM API 注册页面](/screenshots/zzm-register-form.png)

## 登录页长什么样

如果你已经有账号，直接回登录页填用户名和密码即可。

![ZZM API 注册登录页面](/screenshots/zzm-login.png)

## 登录后先看什么

登录后先确认这几个入口能打开：

- `数据看板`
- `令牌管理`
- `钱包管理`
- `操练场`
- `API 信息`

![ZZM API 控制台首页与 API 信息](/screenshots/zzm-console-api-info.png)
