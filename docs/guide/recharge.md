# 充值 / 续费

首次充值建议先小额测试，确认模型、分组和工具配置都能正常使用后，再按需充值。

## 充值入口

- 充值页：<https://zzmapi.zzmsgdsg.xyz/console/topup>
- 控制台首页：<https://zzmapi.zzmsgdsg.xyz>

## 充值手续费

在线支付可能会产生充值手续费，页面或收银台显示的最终支付金额为准。

如果你要大额充值，可以加 QQ 群联系群主人工充值，可免除充值手续费，50 起处理。

QQ群：`1098412601`

加群入口：[QQ 群 1098412601](https://qm.qq.com/q/wKACZYaaTS)

## 充值方式

现在常用两种：

- 控制台内直接充值
- QQ 群联系群主人工充值

在线充值适合小额和即时到账。人工充值适合金额较大、希望免手续费或需要先确认发票/企业用途的场景。

## 常用充值建议

| 场景 | 建议 |
| --- | --- |
| 第一次使用 | 先小额充值并测试目标模型 |
| 长期跑工具 | 每个工具单独建 Key，避免排查混乱 |
| 大额充值 | 加群联系群主，50 起可免充值手续费 |
| 需要发票 | 充值完成后去工单 / 发票页面提交申请 |

## 到账后检查

充值完成后，先看：

1. 钱包余额是否变化
2. 控制台测试能不能正常调用
3. 目标模型有没有权限

如果余额到了，但工具里还是报错，先做一次控制台测试。

## 需要发票怎么办

充值完成后，不是在充值时勾选发票，而是到工单里对已完成订单提交申请。

- 工单 / 发票：<https://zzmapi.zzmsgdsg.xyz/tickets>
- 详细说明：[工单 / 发票](/guide/tickets-invoice)

## 续费时要注意

- 续费通常不用改工具配置
- 工具正在使用的 Key 建议保留
- 续费后优先看余额，再查工具配置

## 没到账怎么办

进群时带上这些：

- 订单号或支付截图
- 充值时间
- 登录账号

提供截图时请打码完整 API Key。
