# 充值 / 续费

先少量充一笔，确认模型能用，再继续加。

## 充值入口

- 充值页：<https://zzmapi.zzmsgdsg.xyz/console/topup>
- 控制台首页：<https://zzmapi.zzmsgdsg.xyz>

## 充值方式

现在常用两种：

- 控制台内直接充值
- QQ 群联系群主转账

QQ群：`1098412601`

加群入口：[QQ 群 1098412601](https://qm.qq.com/q/wKACZYaaTS)

![ZZM API 充值页，标注充值区域和余额位置](/screenshots/zzm-topup-highlight.png)

## 到账后检查

充值完成后，先看：

1. 钱包余额是否变化
2. 操练场能不能正常调用
3. 目标模型有没有权限

如果余额到了，但工具里还是报错，先去操练场测同一个模型。

## 续费时要注意

- 旧 Key 一般不用重建
- 工具里保存的是旧 Key，就别手滑删掉
- 续费后优先看余额，不要先怀疑配置

## 没到账怎么办

进群时带上这些：

- 订单号或支付截图
- 充值时间
- 登录账号

不要发完整 API Key。
