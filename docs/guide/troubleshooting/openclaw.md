# OpenClaw 专项问题

如果你在用 OpenClaw 或类似第三方外接工具，问题多数还是出在地址、Key 和模型权限。

## 先确认是不是工具本身的问题

先做三步：

1. 去 [操练场](https://zzmapi.zzmsgdsg.xyz/console/playground) 测同一个模型
2. 用同一个 Key 试 Claude Code 或 Codex 本体
3. 再回到 OpenClaw 里测

如果本体正常、OpenClaw 不正常，优先看它自己的适配方式。

## 常见原因

- 地址填错
- 该工具要求 `/v1`，你却填了根域名
- 或者相反，本来该填根域名却多写了 `/v1`
- 使用了当前分组不支持的模型
- 工具内部兼容层和官方接口字段不一致

## 最稳妥的排法

- 先换成最基础、最常用的模型
- 换一个新建的专用 Key
- 用最短请求测试
- 成功后再慢慢加复杂配置

## 还不行时

带这些去问最有效：

- 工具名和版本
- 当前填写的地址格式
- 模型名
- 报错截图
- 操练场结果
