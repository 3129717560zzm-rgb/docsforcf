# 权限类问题

模型不可用时，先看 Key 分组和模型权限。

### 先看分组

常用推荐：

| 工具 | 推荐分组 |
| --- | --- |
| Claude Code | `claude专用稳定` |
| Codex | `Codex混池` |

![创建令牌页面中的分组下拉框](/screenshots/zzm-token-create-group-dropdown.png)

### 模型和分组并非全通

不同分组能用的模型不一样。

按这个顺序查：

1. 打开 [模型与分组页面](https://zzmapi.zzmsgdsg.xyz/pricing)
2. 看当前模型在哪些分组可用
3. 回到令牌页确认当前 Key 选的分组

### 同一个账号，不同工具表现不一致

一般是：

- 两个工具用的不是同一个 Key
- 两个 Key 选的分组不同
- 一个地址带 `/v1`，一个没带

### 处理方式

按工具分开检查：

- Claude Code 看 Claude 对应分组
- Codex 看 Codex 对应分组
- 每个工具只保留当前要用的那份配置

这样更容易定位是哪一项配置不一致。

### 按工具单独建 Key

多个工具共用同一个 Key 时，排查时需要同时确认：

- 分组是否匹配
- 模型是否可用
- 工具地址是否对应协议
- 配置是否已经刷新
