# 缓存与计费类问题

先检查余额。

### 先看余额

- 充值页：<https://zzmapi.zzmsgdsg.xyz/console/topup>
- 控制台首页：<https://zzmapi.zzmsgdsg.xyz>

如果工具报 `余额不足`、`额度不足`、`insufficient`，先看这里。

### 续费后还是报错

按顺序查：

1. 余额是否真的到账
2. 控制台测试能不能正常调用
3. 当前模型是否有权限
4. 工具实际读取的是哪份配置

### 多个 Key 时容易搞混

一个工具一个 Key，排查时更清楚。

重点看：

- 当前工具里填的是哪个 Key
- 终端环境变量有没有覆盖配置文件
- 插件有没有缓存上一次的配置

### 缓存相关

有时不是余额问题，是上游缓存或状态还没刷新。

先试：

- 退出工具重开
- 换短请求再测
- 去控制台测试同一个模型

### 排查顺序

如果你分不清到底是余额、缓存还是配置：

1. 去控制台测试同一个模型
2. 看余额是否到账
3. 确认本地工具读取的是当前 Key
4. 完全退出工具后再重开
