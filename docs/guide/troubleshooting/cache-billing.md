# 缓存与计费类问题

先确认是不是单纯没额度。

### 先看余额

- 充值页：<https://zzmapi.zzmsgdsg.xyz/console/topup>
- 控制台首页：<https://zzmapi.zzmsgdsg.xyz>

如果工具报 `余额不足`、`额度不足`、`insufficient`，先看这里。

### 续费后还是报错

按顺序查：

1. 余额是否真的到账
2. 操练场能不能正常调用
3. 当前模型是否有权限
4. 工具是不是还在用旧 Key

### 多个 Key 时容易搞混

一个工具一个 Key 最好排查。

尤其是：

- 老 Key 已删
- 新 Key 充了钱
- 工具里却还挂着老 Key

### 缓存相关

有时不是余额问题，是上游缓存或状态还没刷新。

先试：

- 退出工具重开
- 换短请求再测
- 去操练场测同一个模型

### 最省事的排法

如果你分不清到底是余额、缓存还是旧 Key：

1. 去操练场测同一个模型
2. 看余额是否到账
3. 确认本地工具用的是新 Key
4. 完全退出工具后再重开
