# 疑难解答

先别乱改配置，按顺序查。

## 先做这三步

1. 去 [操练场](https://zzmapi.zzmsgdsg.xyz/console/playground) 测同一个模型
2. 去 [令牌页](https://zzmapi.zzmsgdsg.xyz/console/token) 看 Key 还在不在
3. 去 [充值页](https://zzmapi.zzmsgdsg.xyz/console/topup) 看余额够不够

## 最常见的三个原因

1. 地址填错
2. Key 不可用
3. 选了不匹配的分组或模型
