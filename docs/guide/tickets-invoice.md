# 工单 / 发票

工单用于处理充值售后、发票申请和需要人工确认的问题。

## 入口

- 工单页面：<https://zzmapi.zzmsgdsg.xyz/tickets>

登录后可以查看自己的工单、提交新工单、补充资料和下载已经交付的电子发票。

## 发票申请流程

1. 完成充值
2. 打开 [工单 / 发票](https://zzmapi.zzmsgdsg.xyz/tickets)
3. 选择可开票的充值订单
4. 选择票种：普票或专票
5. 填写开票资料
6. 按页面提示确认服务费
7. 管理员处理并回填发票信息
8. 用户在工单详情中下载电子发票

发票申请不是充值时勾选，而是充值完成后再针对订单提交。

## 需要填写什么资料

不同票种需要的信息不同。页面会按票种展示字段。

### 普票

通常需要：

- 发票抬头
- 纳税人识别号
- 接收邮箱
- 开票金额
- 备注或特殊要求

### 专票

通常还需要：

- 单位名称
- 纳税人识别号
- 注册地址
- 注册电话
- 开户银行
- 银行账号
- 接收邮箱

资料不完整时，管理员可能会把工单改为“需补充”，你需要回到工单详情继续补资料。

## 服务费说明

发票服务费按页面预览为准。当前规则会覆盖固定成本和比例成本。

| 开票金额 | 服务费规则 |
| --- | --- |
| 低于 500 | 按最低服务费处理 |
| 500 及以上 | 按比例或最低服务费中较高者处理 |

如果页面显示需要支付服务费，请先完成服务费支付，再等待管理员处理。

## 电子发票怎么给我

管理员处理完成后，会把电子发票文件绑定到工单。

推荐流程是：

1. 管理员上传电子发票文件或填写文件地址
2. 系统通过站内邮箱通知你
3. 你登录后台
4. 打开工单详情
5. 下载电子发票

为了安全，建议从站内工单下载，不建议在公开聊天里发送完整发票文件链接。

- 需要处理的问题
