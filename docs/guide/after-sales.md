# 售后群

排查不了的时候，再进群问。先把信息带齐，群里会先看这些。

## 群号

- QQ 群：`1098412601`
- 加群链接：[QQ 群 1098412601](https://qm.qq.com/q/wKACZYaaTS)

添加群时写明来意，方便群里分流。
如果是充值后遇到问题，同时带上订单号或充值时间。

## 进群前先做这三步

1. 去 [控制台测试](https://zzmapi.zzmsgdsg.xyz/console/playground) 测同一个模型
2. 去 [令牌页](https://zzmapi.zzmsgdsg.xyz/console/token) 确认 Key 还在
3. 去 [充值页](https://zzmapi.zzmsgdsg.xyz/console/topup) 确认余额正常

## 提问时带这些

- 使用的软件名和版本
- 使用的模型名
- 报错原文或截图
- 出错时间
- 控制台调用日志时间

## 提交信息时请打码

- API Key 只保留后几位，其余打码
- 配置文件截图或片段需隐藏 Key、账号和本地路径
- 请同时提供软件名、模型名、报错原文和出错时间

## 常见分流

- 配置类问题：先看 [教程](/guide/)
- Codex 问题：先看 [Codex CLI 专项问题](/guide/troubleshooting/codex)
- 401 / 403 / 429：先看 [请求错误类问题](/guide/troubleshooting/request-error)
- 网络异常：先看 [网络与连接类问题](/guide/troubleshooting/network)
