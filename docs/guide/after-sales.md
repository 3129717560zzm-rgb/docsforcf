# 售后群

排查不了的时候，再进群问。先把信息带齐，处理会快很多。

## 群号

- QQ 群：`1098412601`
- 加群链接：[QQ 群 1098412601](https://qm.qq.com/q/wKACZYaaTS)

## 进群前先做这三步

1. 去 [操练场](https://zzmapi.zzmsgdsg.xyz/console/playground) 测同一个模型
2. 去 [令牌页](https://zzmapi.zzmsgdsg.xyz/console/token) 确认 Key 还在
3. 去 [充值页](https://zzmapi.zzmsgdsg.xyz/console/topup) 确认余额正常

## 提问时带这些

- 使用的软件名和版本
- 使用的模型名
- 报错原文或截图
- 出错时间
- 控制台调用日志时间

## 不要发这些

- 不要发完整 API Key
- 不要把本地配置文件整段贴出去
- 不要只说一句“不能用了”

- 配置类问题：先看 [教程](/guide/)
- Codex 问题：先看 [Codex CLI 专项问题](/guide/troubleshooting/codex)
- 401 / 403 / 429：先看 [请求错误类问题](/guide/troubleshooting/request-error)
